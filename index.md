# Dataset
The hyperlink network represents the directed connections between two subreddits, or in other words, between two communities. The network is extracted from publicly available Reddit data of 2.5 years from January 2014 to April 2017.

The subreddit-to-subreddit hyperlink network is extracted from the posts that create hyperlinks from one subreddit to another. We say a hyperlink originates from a post in the source community and links to a post in the target community. Each hyperlink is annotated with three properties: the timestamp, the sentiment of the source community post towards the target community post, and the text property vector of the source post. The network is directed, signed, temporal, and attributed.

This dataset consists of two networks of subreddit-to-subreddit hyperlinks which are extracted from hyperlinks in the body of the post, or in the title of the post. The datasets that we will use are available in *Data*: soc-redditHyperlinks-body.tsv and soc-redditHyperlinks-title.tsv.
